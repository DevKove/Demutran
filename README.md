# DEMUTRAN

Sistema de Gestão do Departamento Municipal de Trânsito.

## Módulos
- Início: painel operacional e indicadores.
- Material: catálogo, estoque e movimentações.
- Usuários: cadastro e permissões.
- Vistorias: agendamento, inspeção e histórico.
- Ordens de Serviço: abertura, execução e acompanhamento.
- Escala: equipes, agentes, turnos e plantões.

## Identidade visual
- Amarelo institucional: `#F5C400`
- Preto/grafite: `#171717` / `#242424`
- Fundo claro: `#F4F5F7`

## Stack inicial
React, TypeScript e Vite. A camada de dados e autenticação será integrada após a definição do ambiente de produção.

## Desenvolvimento
```bash
npm install
npm run dev
```

> O repositório estava vazio no momento da inicialização. Esta é a estrutura inicial da interface, ainda sem persistência de dados ou autenticação conectada.
